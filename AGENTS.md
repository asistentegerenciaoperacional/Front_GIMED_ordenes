# Front de GIMED

Trabaja con el [estándar del front](docs/estandares.md) y el sistema visual existente. Para reglas del negocio consulta el glosario de Back_GIMED_ordenes y las skills de este repositorio. Antes de integrar cambios sustanciales, aplica `gimed-rendimiento`. Los contratos de API se regeneran desde el back. Las comprobaciones de paridad utilizan datos sintéticos en modo legacy.
